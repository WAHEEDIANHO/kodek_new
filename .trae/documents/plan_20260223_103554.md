# Plan: Implement Content Conversion Page

## 1. Create Content Conversion Component
- Generate a new component `ContentConversion` in `src/app/pages/content-conversion/`.
- This component will be standalone.

## 2. Configure Routing
- Update `src/app/app.routes.ts`:
  - Import `ContentConversion`.
  - Add a route: `{ path: 'content-conversion', component: ContentConversion }`.

## 3. Implement Content Conversion Page (`content-conversion.html/css/ts`)
- **Structure**:
  - **Tabs Navigation**: A sticky or prominent tab bar (e.g., "Overview", "Digital Learning").
  - **Content Area**: A container displaying the active tab's content.
- **Content**:
  - **Overview Tab**: Three cards as per the reference: "Off-the-Shelf Courses", "Compliance Courses", "Soft Skills".
  - **Digital Learning Tab**: A section describing digital learning solutions with text and an image.
- **Styling**:
  - Use Tailwind CSS.
  - Ensure the layout is responsive (stack cards on mobile, grid on desktop).
  - Consistent typography and colors (green/white theme).
- **Functionality**:
  - **Tabs State**: Track the active tab index.
  - **GSAP Animations**:
    - Animate the content container: Fade out current content -> Fade in/Slide in new content.
    - Animate the tab underline/indicator.
  - **Scroll/Swipe Gestures**:
    - **Mobile**: Implement touch swipe detection (left/right) to switch tabs.
    - **Desktop**: Implement a mouse wheel listener on the content area. If the user scrolls up/down while hovering the content, switch tabs (debounced).
    - **Fallback**: Standard click navigation on tabs.

## 4. Verification
- Verify the route `/content-conversion` loads the page with the main navbar visible.
- Verify clicking tabs switches content with smooth GSAP animations.
- Verify swipe gestures on mobile switch tabs.
- Verify mouse wheel on desktop switches tabs (if implemented) or just verify scroll behavior.
- Verify responsiveness.
